# Menu-Driven Calculator in C

## Description
This project is a menu-driven calculator developed using the C programming language. It uses separate functions to perform addition, subtraction, multiplication, division, and modulus operations based on the user's choice.

## Features
- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division with zero-division checking
- Modulus operation for integers
- Repeated menu until the user chooses Exit
- Invalid choice handling

## Concepts Used
- Functions
- Switch statement
- Do-while loop
- Conditional statements
- Arithmetic operators
- User input and output

## How to Compile and Run
```bash
gcc menu_calculator.c -o menu_calculator
.\menu_calculator.exe
```

## Language
C
